# 📌 Proyecto Destacado

## 🛒 Proyecto-de-Recomendacion-InsightLab

Sistema inteligente de recomendación para e-commerce basado en Machine Learning y reglas de asociación.

### Principales funcionalidades

- 📊 Análisis Exploratorio de Datos (EDA)
- ⚙️ Feature Engineering
- 🤖 Entrenamiento y evaluación de modelos supervisados
- 🧠 Motor de recomendaciones mediante reglas de asociación
- 🚀 API REST desarrollada con FastAPI
- 🐳 Contenerización con Docker
- 🔄 Automatización mediante GitHub Actions
- 📈 Monitoreo de modelos
- 📊 Dashboard interactivo con Streamlit
